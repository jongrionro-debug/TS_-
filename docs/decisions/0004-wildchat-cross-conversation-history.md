# ADR-0004: 사용자별 대화 간 이력 재검증 (validation 전용)

- 상태: 채택
- 날짜: 2026-11-05
- 관련: Issue #21, [ADR 0003](0003-wildchat-category-condition-c.md)

## 맥락

사용자가 승인한 시계열성 부여 1번 방안에 따라 같은 사용자 프록시의 다른 대화에서 관측된 출력 길이를 추가한다. 기존 B는 같은 대화 안의 lag만 쓰며, #19의 C_emb_PCA는 B에 MiniLM 임베딩 PCA를 추가한다. 완료된 최종 평가는 보존하고 이번 비교는 validation에 한정한다.

## 결정

- 사용자 키는 #13과 동일한 대화 행의 `hashed_ip`다. `header`를 결합하면 기존 사용자 분리가 달라지므로 결합하지 않는다. IP 공유·변경에 따른 식별 오차는 남는다. 원본 값은 결과·로그에 저장하지 않는다.
- 원본 단일 train Parquet에서 허용된 train/validation 원본 행의 메타데이터만 연결한다. `conversation`의 `role`·`timestamp` leaf만 투영하며 `content`는 읽지 않는다. `header`(accept-language/user-agent), IP 유래 `country`/`state`, 기록 모델 `model`은 결측 감사에만 사용한다. 이 변수들의 별도 효과를 혼합하지 않도록 모델 입력에는 넣지 않는다.
- WildChat의 UTC assistant `timestamp`는 전체 응답을 백엔드에서 수신한 시각이며 user 제출시각은 아니다. 행 `timestamp`도 대화 마지막 기록시각이므로 현재 요청의 기준 시각으로 쓰지 않는다. 기존 의미 근거는 [감사 보고서](../../wildchat/results/data_audit.md)다.
- 각 예측 행의 보수적 기준 시각은 같은 대화의 **앞선 assistant 완료 시각**이다. 현재 user 제출보다 앞서 관측됐다는 기존 B의 관측 가정을 따른다. 첫 턴에는 이 기준이 없으므로 이력·시간대·요일을 결측 처리한다. 현재 assistant 완료 시각으로 대체하지 않는다. 앞선 메시지의 시각 결측·역전만 현재 기준을 무효화한다. 현재/미래 시각의 품질 판정은 앞선 행에 소급 적용하지 않는다. 대화 전체 시각 불일치는 그 대화의 완료 통계 공개만 차단하며 고정 표본은 유지한다.
- 다른 대화의 전체 통계는 그 대화가 **완료된 후에만** 공개한다. 같은 split 내부에서 완료 시각이 기준보다 엄격히 이른 동일 사용자의 대화만 사용한다. 진행 중 대화와 동시각은 제외한다. 현재 원본 대화 및 현재 중복 그룹은 항상 제외한다. 사용자별 중복 그룹은 가장 먼저 완료된 원본 행 하나만 대표한다.
- 고정 표본의 유효 출력들로 직전 완료 대화의 평균·중앙값, 대화 평균 EWMA(α=0.3) 및 log1p, 완료 대화 수, 직전 완료와의 초 간격을 만든다. 기준 시각의 UTC 시간대·요일과 결측 지표를 추가한다.
- #13의 사용자/그룹 분리와 train 내부 시간순 80/20 경계를 유지한다. outer train/validation과 inner fit/holdout 각각에서 이력을 새로 만든다. inner holdout에 inner fit 이력을 넘기지 않는다. validation에서는 같은 validation의 앞선 완료 정답을 순차 관측하되 모델 학습·선택에는 사용하지 않는다.
- B, C_emb_PCA, B_cross_hist, C_emb_PCA_cross_hist의 네 조건에 동일한 3개 LightGBM 후보·최대 500회·40회 무개선 조기 종료·내부 행 가중 평균 pinball 선택을 적용한다. PCA 조건의 k∈{8,16,32}도 내부에서 선택한다. PCA는 내부 fit에만 적합하고 최종 예측 때 전체 정제 train에 다시 적합한다. 선택 반복 수로 전체 train에 재학습하고 validation은 보고에만 사용한다. 기존 #19의 46.3373은 B 설정을 고정한 별도 절차임을 명시한다.
- 분위수는 음수만 0으로 자르고 정렬하지 않는다. 전체/첫 턴/후속 턴 × 행/사용자 가중의 전체 지표를 보고한다. 평가 중 인과적 이력이 있는 행을 하나 이상 가진 사용자와 없는 사용자를 별도로 보고하며 이 구분은 설명용 평가 strata다. 모델 입력으로 사용하지 않는다.
- 사용자 단위 짝지은 bootstrap(seed 42, 1,000회)은 모든 조건·턴·가중·사용자 구분에서 같은 추출을 공유한다. 두 cross-hist 추가 효과의 평균 pinball 차이와 percentile 95% CI를 기록한다. 재학습·재선택은 하지 않는다.

## 대안과 한계

- 현재 assistant 완료시각이나 행 마지막 시각을 요청시각의 대용으로 쓰면 현재 응답 중 발생한 다른 대화의 정답을 포함할 수 있어 채택하지 않는다.
- 실제 요청시각이 없으므로 첫 턴의 대화 간 이력 활용 효과는 이번 자료에서 검증할 수 없다. 보수적 하한은 실제로 이용 가능했을 일부 이력을 누락할 수 있다.
- 반복 사용된 validation, 첫 샤드 고정 표본, IP 프록시 및 고정 모델 조건부 CI의 한계를 유지한다. 실제 사용량·GPU 효과를 주장하지 않는다. 추가 실험이나 최종 평가 재실행을 승인하는 결정이 아니다.
