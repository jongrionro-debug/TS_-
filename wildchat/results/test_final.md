## 재현 기록과 한계

[고정 설정](test_final_config.json), [해시](test_final_config.sha256), [실행 로그](test_final.log), [전체 결과](test_final.json)에 설정·모델 해시·시각·시드·분할·원시 진단·모든 기준선 대비 CI를 기록했다. 최선 기준선은 #13 내부 홀드아웃에서 이미 선택한 것을 유지한다. bootstrap 중 재학습·재선택하지 않는다.

CI는 사용자 G명에서 G명을 복원 추출하는 짝지은 percentile(선형 보간)이다. 모든 모델·턴·가중 방식에 같은 추출을 쓴다. 모델 학습·선택 불확실성, 시간 상관, hashed_ip 프록시 오차는 포함하지 않는다. 첫 샤드의 다른 기간이며 test는 기존 train/validation 사용자도 제외했으므로 모집단 차이가 있다. validation 대비 차이는 시간 변화와 사용자 구성 변화를 합친 관측이며 원인별 효과를 분리하지 않는다. 기록시각은 실제 요청 도착시각이 아니며 가시 텍스트 재구성 토큰을 평가한다.

```sh
/workspace/venvs/wildchat/bin/python wildchat/finalize.py freeze
/workspace/venvs/wildchat/bin/python wildchat/finalize.py evaluate
```

위 명령은 실행 이력이다. log/result가 존재하면 재평가는 거부한다. 실패한 시도도 로그를 보존하며 재시도하지 않는다.
