# 12페이지 그래프 수정 검토안

상태: 2026-10-23 검토용 제안. 기획 기준은 `docs/prd.md`이며, 이 제안은 예측 목표·특징·지평을 변경하지 않는다. 기존 발표 PDF와 PRD는 편집하지 않았다.

최신 슬라이드 표기는 [직접 수정용 시안](slide_mockups/readme.md)을 따른다. 사용자 요청에 따라 그래프·통계표는 영어로 표기하고 보조 주석은 슬라이드에서 제거했다. 아래 항목은 분석·초기 검토 근거로 보존한다.

## 확인 순서와 결과

1. **그릴 값의 정의**: `08_active_sessions_and_demand.csv`의 `next10_input_tokens`, `next10_final_output_tokens`를 사용한다. 저장된 1분 집계에 누적합을 적용했을 때 모든 158,328개 예측 시점에서 요청 수·입력·출력 목표값이 정확히 일치했다. 겹치지 않는 `04_series_10min.csv`와 구분한다. 이번 검증 범위는 저장된 두 집계 결과의 정합성이며 원본 이벤트 EDA 전체 재실행은 아니다.
2. **하루 예시 선정**: 전체 기간의 첫 60%에서 완전한 하루를 골라, 일별 입력 목표 평균의 중앙값에 가장 가까운 날을 선택했다. 상대 일 인덱스 5, 즉 관측 첫날을 1일째로 세면 6일째다. 입력 수요 기준으로 고른 설명용 예시이며 입력·출력의 모든 특성을 대표한다고 해석하지 않는다. 이 계산은 모델 분할 경계나 출력 정답 적격성의 확정 작업이 아니다.
3. **하루 예시 외에도 시간대 차이가 있는지**: 위 기준으로 확보한 완전한 64일 모두에서, 09–18시의 평균 10분 입력·출력 목표값이 00–08시보다 높았다. 시간대 특징을 고려할 동기이며, 특징의 추가 예측가치를 입증한 결과는 아니다.
4. **전체 기간 그림의 필요성**: 첫 30일과 마지막 30일의 평균 10분 입력 목표는 약 9,282 → 23,523토큰, 출력은 2,599 → 6,857토큰이었다. 따라서 단기 변동과 함께 기간별 수요 수준 차이를 보여줄 가치가 있다. 그림만으로 변화 원인이나 엄밀한 비정상성을 확정하지 않는다.
5. **110일 원시값의 가독성**: 원시값을 옅게 그리고 일별 평균선을 진하게 겹친 시안에서는 피크와 기간별 수준 차이를 함께 읽을 수 있다. 시간별 평균으로 축약한 대안도 생성했지만, 본문에는 원시값 시안을 우선 추천한다.
6. **10분 선택의 설명 범위**: 5·10·15분이 모두 완전한 동일 158,323개 시점에서 목표 0 비율을 비교했다. 후속 간격 비율은 기존 관측 후속 요청 쌍 177,697개를 분모로 한다. 두 지표의 분모는 다르다.

| 지평 | 관측 후속 요청 간격이 지평 이내인 비율 | 입력 목표 0 비율 | 출력 목표 0 비율 |
|---|---:|---:|---:|
| 5분 | 66.1% | 22.3% | 22.3% |
| 10분 | 76.7% | 15.8% | 15.8% |
| 15분 | 81.6% | 12.6% | 12.6% |

15분을 추가한 공통 시점 비교는 기존 5·10분 요약보다 끝의 5개 시점이 적다. 소수 둘째 자리까지 표시하면 10분 0 비율은 기존 표의 15.81%와 달리 15.82%다. 발표에서는 위처럼 소수 첫째 자리로 통일할 수 있다.

## 권장 수정안

- **12페이지 제목**: `EDA ① TARGET DEMAND` 또는 `예측 대상의 단기 변동과 전체 추이`.
- **왼쪽**: 선정한 하루의 매 1분 예측 시점별 다음 10분 누적 목표. 입력 위, 최종 출력 아래.
- **오른쪽**: 같은 목표의 전체 약 110일 원시 시계열을 옅게 표시하고 일별 평균선 추가. 같은 행의 좌우는 같은 y축 범위로 비교한다.
- **그래프 설명**: ‘평균선은 10분 목표값의 일별 평균’이라고 표시한다. 일별 총토큰으로 해석하지 않는다. 출력은 도착 요청에 귀속되는 최종 출력량이며 구간 내 실제 생성량이 아니다.
- **본문 문구**: ‘토큰 수요는 하루 안에서도 변동하며, 관측 기간에 따라 수요 수준에도 차이가 있다. 최근 수요 이력과 하루 중 시각을 공통 입력 후보로 사용하고, 예측 효과는 시간순 검증으로 평가한다.’
- **하단 각주**: ‘1분마다 계산한 다음 10분 누적 목표이며 인접 목표 구간은 9분 겹친다.’ 매끄러운 곡선 자체로 최근 이력의 예측력이나 10분의 적절성을 주장하지 않는다.
- **기존 ACF·시간대 평균 그림**: 발표 부록 또는 EDA 근거로 보존한다. 하루 예시만으로 일중 패턴을 일반화하지 않는다.
- **다음 대화 EDA 페이지**: 위 5·10·15분 비교를 작은 표로 추가한다. ‘10분은 후속 요청 포괄 범위와 단기성 사이의 설계 선택이며, 최적 지평이라는 주장은 아니다’라고 명시한다. 관측 후속 쌍의 간격 분포를 전체 요청의 재방문 확률로 표현하지 않는다.
